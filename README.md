# 📚 myBookShelf

myBookShelf adalah aplikasi web yang dirancang sebagai katalog literasi digital pribadi untuk melacak koleksi buku, membaca ulasan, dan menyimpan buku favorit.

## ✨ Fitur Utama

- **🏠 Home View**: Menampilkan seluruh koleksi buku.
- **📖 Review Detail**: Halaman khusus untuk membaca deskripsi singkat dan ulasan lengkap buku.
- **👤 Dynamic Profile**: Halaman profil pengguna yang terintegrasi dengan data buku. Statistik jumlah buku ("Books Read", "Reviewed", dan "Favorites") akan dihitung dan diperbarui secara otomatis.
- **📱 Responsif Sepenuhnya**: Tampilan UI/UX yang beradaptasi sempurna di berbagai ukuran layar (Desktop, Tablet, dan *Smartphone*).

## 🛠️ Teknologi yang Digunakan

Proyek ini dibangun menggunakan teknologi *front-end* murni tanpa memerlukan proses *build* atau dependensi eksternal yang rumit:
- **HTML5**: Struktur semantik web.
- **CSS3**: *Styling* dengan CSS Flexbox & Grid, CSS Variables untuk tema pastel, serta Media Queries untuk desain responsif.
- **Vanilla JavaScript (ES6+)**: Manipulasi DOM, pengelolaan *state* navigasi (SPA *routing* sederhana), dan interaktivitas.
- **FontAwesome**: Ikon web.
- **Google Fonts**: Tipografi (Poppins).
